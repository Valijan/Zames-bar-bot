# Бот учёта бара ZAMES

Telegram-бот для рабочей группы. Он читает сообщения в темах «Приход», «Списание», «Перемещение», «Продажи» и «Инвентаризация» и ведёт остатки. Продажи берёт с фото отчёта iiko и сам списывает ингредиенты по техкартам. Считает фудкост и присылает отчёты с CSV-файлом.

## Установка (один раз, ~15 минут)

1. **Взять токен старого бота food cost.** В Telegram откройте @BotFather → `/mybots` → ваш бот food cost → **API Token** → скопируйте.
   Затем там же: `/setprivacy` → выберите этого бота → **Disable**. Без этого бот не видит сообщения в группе.
   Новый код полностью заменит старую логику бота. Имя и @username останутся, кнопка Mini App уберётся.
2. **Ключ Gemini (бесплатно)** нужен для чтения фото: https://aistudio.google.com/apikey → Create API key.
3. **GitHub.** Создайте пустой репозиторий `zames-bar-bot` и загрузите туда файлы из архива: Add file → Upload files, перетащите все папки.
4. **Vercel.** https://vercel.com/new → Import этого репозитория → Deploy.
5. **База.** В проекте Vercel: Storage → Create → **Upstash (Redis)** → Free → Connect to project. Переменные базы добавятся сами.
6. **Переменные.** Settings → Environment Variables:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1
   - `GEMINI_API_KEY` — ключ из шага 2
   - `SETUP_KEY` — любое слово-пароль, например `zames2026`
   - `WEBHOOK_SECRET` — любая длинная строка из букв и цифр
   После этого: Deployments → ⋯ → **Redeploy**.
7. **Подключить Telegram.** Откройте в браузере `https://<ваш-проект>.vercel.app/api/setup?key=<SETUP_KEY>`. Должно появиться `"ok":true`.
8. **Группа.** Добавьте бота в рабочую группу и сделайте его администратором. Напишите в группе `/id` и получите id группы.
   Добавьте переменную `ALLOWED_CHATS` = этот id (так бот будет работать только в вашей группе) → Redeploy.

## Как пользоваться

**В группе бот молчит.** Записал — ставит на сообщение 👍, не понял — 🤔 (что именно, смотрите `/problems`).
**Отчёты** (`/report`, `/foodcost`, `/stock`, `/log`, `/problems`) приходят в личку тому, кто спросил. Для этого надо один раз нажать «Старт» в личке бота.
**Каждое утро в 9:00** бот сам присылает отчёт за вчера тому, кто первым нажал «Старт» (или написал `/owner` в личке).
**Фото:** в «Продажах» — отчёт iiko (если сумма сходится с «Итого Бар», продажи вносятся сами); в «Приходе», «Списании» и «Перемещениях» — накладные и списки. Нужен `GEMINI_API_KEY`.


Темы в группе называйте так: **Приход**, **Списание**, **Перемещение на кухню**, **Перемещение в пиццерию**, **Перемещение в кондитерскую**, **Продажи**, **Инвентаризация**. Бот понимает тип операции по названию темы. В общем чате тип задаётся первым словом сообщения.

```
Приход
Молоко 12 л 144 000      ← сумма за всю строку
Лимон 5 кг 75000
Кола 48 шт 960 000
```
```
Перемещение в пиццерию
Сливки 10% 1 л
Лимон 500 г
```
**Продажи:** в теме «Продажи» сфотографируйте отчёт iiko «Общие продажи блюд». Можно прислать несколько фото, если отчёт не влезает на один экран. Потом отправьте `/done`.

**Инвентаризация:** напишите фактические остатки, бот покажет недостачу или излишек в граммах и сумах.

Команды: `/stock`, `/report 16.11-20.11`, `/foodcost неделя`, `/tk ассам`, `/price Молоко 1 л 12000`, `/alias сгущ = Сгущенка`, `/undo`, `/help`.

Важно: сначала сделайте одну инвентаризацию, чтобы задать стартовые остатки. Цены закупки бот берёт из приходов с суммой (или из `/price`). Без них фудкост не посчитать.

## Техкарты

Техкарты лежат в `data/seed.json`, привязаны к кодам iiko и загружаются при первом запуске. Классические чаи, фреши, айс-напитки и альтернативное молоко пока заведены с примерными нормами (`"approx": true`).
